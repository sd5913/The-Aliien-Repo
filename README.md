# BothPls

BothPls 是一款 Android 优先、响应式的轻量选择投票原型。创建一个问题，邀请朋友表达偏好，再一起看看结果。

## 本地运行

需要 Node.js 18 或更高版本及 npm。

```bash
npm install
npm run dev
```

使用终端显示的本地地址打开应用。生产构建可通过 `npm run build` 生成到 `dist/`，使用 `npm run preview` 本地预览。

## 当前原型

- 首页、创建投票、公开投票、结果与评论、我的投票及管理页已连通。
- 两个选项使用二选一；三个至六个选项使用可调整顺序的排序投票，并按 Borda 计分。并列分数会保留为并列。
- 投票、评论和昵称保存在当前浏览器的 LocalStorage，不会跨设备同步。清理浏览器数据会移除原型记录。
- 分享链接在本地开发时仅适用于能访问该开发地址、且拥有相同浏览器数据的场景；没有服务端或真实访问控制。管理链接只是原型入口，不是安全凭证。
- 截止时间用于显示开放状态，不由服务器执行；没有登录、永久图片存储或生产级后端。图片目前通过可选图片 URL 预览。
- 投票数据以浏览器为边界，不能用于真实多人实时投票。

## 项目结构

```text
src/
  app/                 路由与应用入口
  components/          页面布局、导航和状态组件
  features/             首页及投票创建、参与、结果、管理页面
  hooks/                投票数据状态
  lib/                  LocalStorage 与投票计分逻辑
  types/                核心领域类型
  styles.css            响应式全局样式
```

仓库原有 Python 数据处理示例文件保留，前端应用作为独立入口新增。
