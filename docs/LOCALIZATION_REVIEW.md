# Web v1.4 本地化分支审查（2026-11-22）

分支：`codex/bothpls-localization`。本文件记录与当前 `main` 的比较结果；它不是已完成合并的声明。

## 当前状态

- 本分支有繁体中文（香港）、英文、韩语各 294 个界面词条。词条键、占位符和非空检查通过。
- 语言入口已收拢到“个人 → 设置” (`/settings/preferences`)；游客也可进入设置页。切换后语言保存在当前浏览器，页面及分享票据会按选定语言重新渲染。用户填写的投票标题、选项、评论和昵称保持原文。
- 当前 `main` 的设置页已有简体中文/英文切换，使用 `bothpls:locale` 值 `zh-CN`/`en-US`；本分支使用相同存储键，但语言值为 `zh-HK`/`en`/`ko-KR`，默认繁体中文。合并前必须统一语言代码、默认中文和旧存储值迁移，否则已选择英文的用户可能回退为中文。
- `git merge-tree --write-tree main codex/bothpls-localization` 检出 22 个内容冲突文件，涉及路由、首页、登录、投票、分享、设置、样式和浏览器测试。两侧代码的页面结构和行为也有差异，不能仅靠自动选择一侧解决。
- 本分支基于 PR #13 附近的页面。主线后来增加的“最近/广场”双 Tab、广场分享权限、纯文本瓶身和卡片预览、结果关闭直接回首页、新版账号设置等内容，在本分支的页面代码和词条中尚未完整覆盖。合并时应以最新 PRD v1.4 和当前主线行为为准，再逐页接入词条。

## 人工翻译审核

1. 先确定最终语言列表及中文默认版本。当前主线是简体中文；本分支的中文词条是繁体香港用语。若要保留简体中文，应补齐简体词条并决定繁体是否作为第四种语言。
2. 打开 `src/i18n/messages/zh-HK.ts`、`en.ts`、`ko-KR.ts`，按相同 key 逐行核对含义。优先审核登录/授权、投票创建与提交、广场分享权限、结果与关闭、注销账号等影响操作判断的文案。
3. 只修改引号中的译文，保持 key 和 `{name}`、`{count}` 等占位符的拼写及数量一致。不要翻译用户自行输入的标题、选项、评论、昵称。
4. 本地运行 `node --test src/i18n/catalog.test.mjs` 和 `npm run build`。前者检查三种语言的词条、占位符和空值；后者检查 TypeScript 与打包。
5. 运行 `cd tools/browser` 后执行 `npm test -- tests/localization.spec.mjs`，逐页打开“个人 → 设置”切换语言。以游客、软登录和正式账号分别检查首页、登录、创建、投票、结果、分享、个人与设置；在窄屏检查换行、按钮宽度、弹窗和无障碍名称。真实第三方 OAuth 页面与 Supabase 邮件需另行人工查看。
6. 记录每条修改的 key、目标语言、原文、修订文、页面截图和审核人；只合入已审核的词条。主线新页面的词条需在解决代码冲突时补录，再做同样检查。

## 待解决的合并决策

- 中文默认：沿用主线 `zh-CN`，或另行明确切换为 `zh-HK`。
- 语言代码：统一英文为 `en-US` 或 `en`，并迁移旧 `bothpls:locale` 值。
- 新版设置、首页及投票链路的词条应基于当前页面重新提取，避免本分支旧页面覆盖主线功能。
